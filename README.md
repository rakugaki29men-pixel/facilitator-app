# 懇親会ファシリテーター

社内懇親会のための、声で進行する司会アプリです。スピーカーにつないだPCのブラウザで動かします。

- PCのマイクで会話をずっと聞き取る（話者の区別はしない。聞き間違いはネタとして使う）
- 一定の間隔で聞き取った内容をAIに渡し、AIが「今割り込むか」と「何を言うか」を決める
- AIがしゃべっている間は音声認識を止める（自分の声を拾って暴走しないように）
- ブラウザの音声認識が勝手に止まったら自動で再起動する
- 幹事用の「次へ」ボタンで、いつでも話題を切り替えさせられる

## 公開のしかた（Render・スマホだけでOK）

APIキーを守るため、キーは Render の設定画面にだけ入れます（ブラウザにもGitHubにも置きません）。
アプリを開く人には「合言葉」を求めるので、アドレスを知られてもAPIは使われません。

1. OpenAI の管理画面でAPIキーを作り、**利用上限額を低め（例：月5ドル）に設定**しておく
2. https://render.com に GitHub アカウントでログインする
3. 「New」→「Blueprint」→ このリポジトリ（`facilitator-app`）を選ぶ
   ※ ブランチは `ccr-0e561db0-crfcsd` を指定する
4. 入力欄が2つ出るので入力する
   - `OPENAI_API_KEY` … OpenAI のAPIキー
   - `FACILITATOR_PASSCODE` … 自分で決めた合言葉（8文字以上、推測されにくいもの）
5. 「Apply」を押して数分待つと、`https://facilitator-app-xxxx.onrender.com` のようなアドレスができる
6. そのアドレスを Chrome で開き、画面の「合言葉」欄に入力して「▶ 開始」

無料プランは、しばらく使わないと止まり、次に開いたとき起動に50秒ほどかかります。
**会が始まる前に一度開いておいてください。**

| 環境変数 | 初期値 | 内容 |
| --- | --- | --- |
| `OPENAI_API_KEY` | （必須） | OpenAI のAPIキー |
| `FACILITATOR_PASSCODE` | （必須） | 画面で入力する合言葉。未設定だとサーバーが起動しない |
| `OPENAI_MODEL` | `gpt-4o-mini` | 使うモデル。返事の速さ重視で小さめのモデルを推奨 |
| `OPENAI_TTS_MODEL` | `gpt-4o-mini-tts` | 読み上げ（音声合成）のモデル。声の演技指示が使えるのはこの系統 |
| `OPENAI_REASONING_EFFORT` | （未設定） | 推論モデルを使うときだけ `low` などを設定 |

### 自分のPCで動かす場合

Node.js 20 以上で、`OPENAI_API_KEY` と `FACILITATOR_PASSCODE` を環境変数に入れて `npm start`、
http://localhost:3000 を開きます。

## 当日の使い方

1. 開始前に設定を入れる（参加者・キャラ・しゃべり方・声）。設定はブラウザに自動保存されます
2. 「🔊 声のテスト」で音量と声を確認
3. 「▶ 開始」で**トーク中画面**に切り替わり、キャラが開会のあいさつをします
   - キャラの絵が、聞き取り中・考え中・しゃべり中で動きます
   - セリフは吹き出しに出ます。聞き取った言葉も字幕のように出るので、聞き間違いも見えます
   - 進行中は画面が消えないようにしてあります
4. 進行が迷子になったら「次へ ⏭」。しゃべっている途中でも打ち切って次の話題へ進みます
5. 「⚙ 設定」で、会を止めずに設定を変えられます。次の判断から反映されます
6. 「■ 停止」で設定画面に戻ります

マイクがなくても、トーク中画面の「ログ・手入力」から文字を入れると「聞き取った」ことにできます（動作確認用）。
設定画面の「AIへの指示文を確認」を開くと、設定がどうAIに伝わっているかが見られます。

## AIがしゃべるタイミング

AIに「今しゃべるか」を聞くきっかけは2つあります（設定の「音声・タイミング」）。

- **定期**：前回の判断から「割り込むかを聞く間隔」の秒数がたつと、AIに聞く。しゃべるかどうかはAIが決めるので、盛り上がっているときは「見送り」になる
- **沈黙**：誰の声も聞こえない状態が「沈黙が続いたら話題を振る」の秒数続くと、AIに必ず話題を振らせる（0でオフ）。AIがしゃべったあとは、また最初から数え直す

## テンション

設定の「テンション」で、司会者の元気さを1（とても静か）〜5（最高潮）で決めます。変化のさせかたは4通りです。

- **一定**：基本のテンションのまま
- **だんだん盛り上げる**：基本のテンションから、指定した時間をかけて最高潮に向かう
- **毎回ランダムに急変**：セリフごとに1〜5をくじ引き（前回と同じにはならない）。静かな回と爆発する回の落差を楽しむ
- **AIおまかせ**：場の空気に合わせてAIが決める

トーク中画面の「−」「＋」で、会を止めずに基本のテンションを上下できます（ランダム急変中は使えません）。
決まったテンションは、セリフの書きぶりと声の演技（OpenAIの声）の両方に反映されます。

## 話の振り方と、上限の回の締めの芸

- **全員への質問はしない**：必ず参加者の誰か1人を名前で呼んで話を振る（参加者が1人も登録されていないときだけ例外）
- **深掘りは続けてOK**：話が広がりそうなら、同じ人に続けて聞いてよい
- **連続の上限**（設定の「話の振り方・締めの芸」。初期値3回）：同じ人に連続で振れるのはこの回数まで。回数を数えるのはアプリ側で、AIには毎回「今回は何回目か」を渡す
- **上限の回は締めの芸**：その人との会話の内容を受けた、5〜10秒ほどのラップか一発ギャグ（設定でチェックしたものからランダム）で締める。一発ギャグのあとは、自分で長めに爆笑する
- 上限まで振った人には、次の発言では振らない。別の人に移ると、またそこから数え直す
- 「次へ」を押すと深掘りを打ち切り、いまの相手には次はすぐ振らない
- トーク中画面に、いま誰と何回目かが出る

芸は、アプリが「セリフ → 芸 → （ギャグなら）爆笑」の順に、声の演技を変えて読み上げます（読み上げごとに少し間があきます）。
歌は、音声合成ではメロディをつけられないので、選択肢に入れていません。

## 参加者ごとの話題・ツッコミ

設定の「参加者」で、名前とひとことメモに加えて、人ごとに次の設定ができます（「話題・ツッコミ設定」を開く）。

- **振りたい話題**：その人に振りたい話（例：週末のゴルフ）
- **ツッコミワード**：その人に使いたいツッコミ（例：また遅刻）
- **触れてはいけない話題（NG）**：遠回しにも触れない。常にAIへの指示に入る
- **絡む頻度**：控えめ(10%)・ふつう(25%)・多め(45%)・しつこいくらい(70%)

話題とツッコミは、セリフを作るたびに**頻度どおりにくじ引き**して、当たった分だけをAIに渡します（AIに頻度を守らせると守られないため）。同時に絡むのは最大2人で、前回絡んだ人は1回休みです（「しつこいくらい」は休みません）。

## 笑い上戸

設定の「笑い上戸」（0:笑わない 〜 4:笑いが止まらない）で、笑い声を入れる確率が決まります（0%・15%・40%・75%・95%）。セリフごとにくじ引きして、当たったときだけ「あはははは！」のような笑いを入れさせ、OpenAIの声には本当に笑っているように演じる指示を付けます。
仕上がりは声の種類しだいです。まず「😂 笑いのテスト」で確認してください。ブラウザの声は、笑いも棒読みになります。

## 声

- **OpenAIの声**（初期設定）：ChatGPTに近い自然な声。声のタイプ（おじいちゃん・おばあちゃん・熱血主人公風・ツンデレ風など）と自由記述の指示、司会者のキャラ設定、テンションが演技に反映される。特定の人物の声をまねることはできない。読み上げのたびに1〜2秒ほど待ち、少し料金がかかる
- **ブラウザの声**：無料だが機械的。OpenAIの声が使えないときは自動でこちらに切り替わる

## しくみ

```
ブラウザ                                          サーバー (server.js)  ※ /api/decide と /api/tts
 ├ speech.js   音声認識(自動再起動) / 読み上げ
 ├ settings.js 設定項目の登録簿・設定画面・保存
 ├ prompt.js   設定 + 聞き取り内容 → AIへの指示文     ─POST /api/decide→  OpenAI API
 └ app.js      タイマー・「次へ」・読み上げ中の聞き取り停止  ←{speak, utterance, reason}─
```

APIキーはサーバー側だけで持ち、ブラウザには渡しません。
AIへの指示文は判断のたびに設定から作り直すので、途中の設定変更がすぐ効きます。

## 設定項目の追加方法

`public/settings.js` の `SECTIONS` に1つ追加するだけです。

```js
{
  id: "game",                       // 保存キー
  title: "ゲーム",                   // 設定画面の見出し
  defaults: { list: "" },           // 初期値
  render(root, value, update) {     // 設定UIを描画。値を変えたら update(value)
    ...
  },
  toPrompt(v) {                     // AIへの指示文に入れる文章（不要なら省略）
    return v.list ? `# 使ってよいゲーム\n${v.list}` : "";
  },
}
```

## 注意

- 音声認識は Chrome / Edge の Web Speech API を使います。音声はブラウザ提供元のサーバーで処理されます
- 認識結果と設定内容（参加者の名前・メモ）は OpenAI API に送られます
